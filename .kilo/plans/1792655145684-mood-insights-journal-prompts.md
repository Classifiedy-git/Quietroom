# Plan: Export AI Weekly Summary as PDF

## Goal
Add a "Save as PDF" button on the Insights page that generates a professional, printable PDF of the AI weekly summary, including the Quietroom logo, ready to share with a therapist.

## Decisions
- **Client-side generation** using jsPDF (loaded from CDN). No server-side dependencies needed — works on shared hosting (Byethost).
- The PDF is generated from the already-rendered summary text (no extra API call).
- Logo embedded as a base64 PNG converted from the SVG at runtime via canvas.
- Professional layout: header with logo + title, date, user name, body text, footer.

## Context
- Insights page (`app/pages/insights.php`) has an "AI weekly summary" card with a "Write my summary" button (`#summary-btn`).
- The summary text is rendered into `#summary-out` after the API call.
- jsPDF is not currently used anywhere in the codebase.
- Logo is at `assets/img/logo.svg` (32x32 SVG with gradient).

## Tasks

### Task 1: Add jsPDF CDN to footer or insights page
**File:** `app/pages/insights.php` (via `$pageScripts`)
- Add `<script src="https://cdnjs.cloudflare.com/ajax/libs/jspdf/2.5.1/jspdf.umd.min.js"></script>` before insights.js
- Only load on insights page to avoid unnecessary weight elsewhere

### Task 2: Add "Save as PDF" button
**File:** `app/pages/insights.php`
- Add button next to "Write my summary" button in the AI weekly summary card:
  ```html
  <button class="btn btn-soft btn-block" id="pdf-btn" disabled>Save as PDF</button>
  ```
- Button disabled until summary is generated
- Enable it in the JS after successful summary generation

### Task 3: Implement PDF generation in insights.js
**File:** `assets/js/insights.js`

Add a function `generateSummaryPDF(text, userName, dateRange)`:
1. Create jsPDF instance (A4, portrait)
2. Convert logo SVG to PNG via canvas:
   - Load SVG as image, draw to canvas, get dataURL
   - Add to PDF at top-left (small, 12x12mm)
3. Add header:
   - "Quietroom" text next to logo (bold, teal)
   - "Weekly Summary Report" subtitle
   - Horizontal rule
4. Add metadata block:
   - Prepared for: [user name]
   - Date range: [since] to [today]
   - Generated: [current date]
5. Add body text:
   - Split text into lines (jsPDF's splitTextToSize)
   - Render with proper line spacing
   - Handle page breaks
6. Add footer on each page:
   - "Generated by Quietroom · quietroom.byethost7.com"
   - Page number
7. Save as `quietroom-summary-YYYY-MM-DD.pdf`

### Task 4: Wire up the button
**File:** `assets/js/insights.js`
- Add click handler on `#pdf-btn`
- Read the summary text from `#summary-out`
- Call `generateSummaryPDF()`
- Show loading state during generation

### Task 5: Style the PDF button
**File:** `app/pages/insights.php`
- Use existing `btn btn-soft btn-block` classes
- Add icon (download or file icon)

## Edge Cases
- If jsPDF fails to load (CDN down), button should be hidden or show error
- If no summary generated yet, button stays disabled
- Long summaries should flow across multiple pages
- Logo conversion failure should fall back to text-only header

## Validation
- Generate PDF from a real summary and verify it opens correctly
- Check logo renders in the PDF
- Check multi-page handling with long summaries
- Test on Chrome and Safari (jsPDF compatibility)

## Files to Create/Modify
- `app/pages/insights.php` — add PDF button + jsPDF CDN script
- `assets/js/insights.js` — add PDF generation function + button handler
- No new PHP files needed (client-side only)
